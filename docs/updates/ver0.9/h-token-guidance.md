# PgO B 区单 H Token 流量修正

日期：2026-10-14。

## 范围

仅用于 PgO 8K 的独立三路 CFG。权重保存于具体 H 事件的
`guidanceWeight`，默认 1，允许 0..10。同一音素在不同位置出现时分别设置。
不解析歌词中的方括号标记，不改变原始 H 的 token ID、帧位置或句界。

在 SYN 编辑器选择普通 H 音素，在现有属性栏修改“B 区权重”。
选中音素后可直接按上/下方向键增减 0.1，范围仍为 0..10，
每次修改可撤销；输入框、其他编辑区域、PUL/SEP/空白帧不触发。
不带修饰键，和 MIDI-P 的 Ctrl+上/下互不干扰。
统一 CFG 模式不允许编辑；带非默认权重的任务必须使用 PgO 独立三路 CFG，
其他模型/模式明确拒绝，不静默忽略。修改支持原有工程保存和撤销/重做。
重新生成/替换 H 事件会得到新事件，不按文字猜测或迁移旧事件的权重；
仅移动原事件时权重随事件保留。

SYN 对象可在其他任务中用作 A，但 A 快照不携带任何 H 权重；
只有当前 B 快照冻结权重。不存在独立的 A 区 H 权重设置。

## 四类 H 与临时空白

| 编辑器输入 | ID | 本功能处理 |
| --- | --- | --- |
| 普通 token | 1..363 | 可设置权重；临时分支只将选中位置置 0 |
| 空白帧 | 0 | 保持不动，不可设置权重 |
| 句界 SEP（界面亦称 SEG） | 365 | 保持不动，不可设置权重 |
| PUL | 366 | 保持不动，不可设置权重 |

PUNCT=364 仍沿用禁用约束。PUL 不是空白帧；局部屏蔽不能写 PUL，
也不能删除元素、移动后续音素或使用 `-1`。

实际模型 TextEmbedding 首先把原输入加 1：输入空白 0 对应 embedding row 1，
SEP 对应 row 366，PUL 对应 row 367。原有全局 `drop_text=True` 则在加 1 后
将整套索引置 0，是不同的 CFG dropout 语义。局部屏蔽前向始终
`drop_text=False`，不引入 `-1`，不把全部 H 清空。

## 计算

以下所有预测都在同一当前状态 x、同一 ODE 时刻 t 求得。

每个参考 i 保留原来的四个分支：

- F_i：A_i、Text/H、MIDI 全部保留。
- N_Ai：只去 A 条件。
- N_Ti：只全局丢弃 Text/H。
- N_Mi：只去 MIDI 条件。

对每个非默认权重的 B 音素 j，另做一次完整条件前向，只把该音素的
joint frame 设为 0，得到 F_i_without_j。所有局部分支使用原始完整 H 的独立
clone，不累计屏蔽，不共享不同参考的预测，不乘第二次 T CFG：

```text
C_i = sum_j ((1 - hWeight_j) * (F_i_without_j - F_i))
```

单 A：

```text
G = F + a*(F-N_A) + t*(F-N_T) + m*(F-N_M) + C
```

多 A 延续现有权重定义：

```text
w_i = 1 + a_i
W = sum_i w_i
r_i = w_i / W

G_i = N_Ai + W*(F_i-N_Ai) + t*(F_i-N_Ti) + m*(F_i-N_Mi) + C_i
G = sum_i (r_i * G_i)
```

先在每个参考内部完成 CFG、求差和局部修正，最后才混合 G_i。
不出现 F_i - F_k_without_j 之类的跨参考运算。
没有非默认 H 权重时沿用原有多 A 算式及运算顺序。

示例 `ko[1.2] to[0.9] a i shi[0.3] te` 中，每个参考内部新增：

```text
C_i = -0.2*(F_i_without_ko-F_i)
      +0.1*(F_i_without_to-F_i)
      +0.7*(F_i_without_shi-F_i)
```

这里的权重是现有 CFG 之后的额外方向修正，不是最终音量或精确条件百分比。
即使权重为 0，也不保证最终结果完全没有该音素；差分可能影响邻音或更大范围。
多个音素修正项相加是一种实验性近似，不能假设其影响完全独立。

## 前向次数与审计

K 个非默认权重、R 个启用参考，每次求场为 R*(4+K) 次前向；
双 A、三个权重即 14 次。每个 Token 独立计算，未加入分支合并优化。
已经设为 A CFG=-1 的参考继续沿用现有跳过规则。多 A 全部禁用时继续走
已有显式 no-A 路径，局部修正在该路径内部计算，不访问已禁用参考。

所有分支显式使用 cache=False；异常退出后恢复原 transformer.forward 并清理缓存。
原始输入不变，只有临时文本 tensor 的一个 B 帧被修改。

权重随素材快照纳入 canonical SHA-256。服务端和 Python runner 均校验数值、
事件身份、帧、token、支持模式，拒绝 A/空白/PUL/SEP 权重。
作业 `audit.json` 的 `tensor.hTokenGuidance` 记录事件身份、
B-local/joint 帧、原始 token、权重、公式、空白 ID 和新增前向数。
需要释放并重新加载已加载的 PgO 常驻运行时，以匹配更新的 runner/guidance 哈希。

## 验证

- CPU 数值测试覆盖单 A、多 A 内部修正、7/14 次调用、原始输入不变、
  四类 H、禁用 A 路径、异常恢复与参数拒绝。
- 使用本机实际 TextEmbedding 做 CPU 检查：局部空白仅改变选中 embedding
  索引，全局 dropout 才把整套索引变为 0。
- 前端事务、快照、服务端校验和 Python runner 测试覆盖权重冻结、
  A 权重排除、哈希变化、非法模式拒绝与时间坐标不变。
- 独立浏览器临时工程验证属性修改、撤销/重做、PUL/SEP 无入口、
  保存刷新后恢复，不修改用户歌曲工程。
- 未运行真实模型 GPU 合成，听感和局部可控性尚待实验。
