# PgO 独立 CFG 与多 A

## 范围

- 仅 `V5PgO_8K` 新生成的三路 CFG Take 使用 `audio-text-midi-independent.v1`。
- 统一 CFG 的定义不变；其他模型保留链式三路 CFG。已完成 Take 的采样设置、音频和哈希不修改。
- 多 A 仅 PgO 支持，不自动混用 PgOV 或 F1 的编码路径。当前采用最多 16 个参考的输入保护限制，逐个分支推理。
- A 区行仍为固定 46px 高，主区域按参考数量均分；每条过窄时使用固定最小宽度并在区域内横向滚动，不改变整行总宽度。
- 双 A 关闭后仍保留主 A 绑定，以及 A2 的选择和 CFG 供下次启用；不改变目标 Segment、H、MIDI 或时间线位置。

## 参数

A1 CFG 沿用现有 A CFG，A2 CFG 单独保存，均允许 [-1, 10]。新建 A2 默认 -1，不增加参考贡献。

```text
w_i = 1 + CFG_i
p_i = w_i / sum(w)
```

单 A 独立 dropout：

```text
v = vFull
  + cA * (vFull - vTM)
  + cT * (vFull - vAM)
  + cM * (vFull - vAT)
```

双 A 正权重和的公式：

```text
v = sum(p_i * vTM_i)
  + sum(w_i * (vFull_i - vTM_i))
  + cT * sum(p_i * (vFull_i - vAM_i))
  + cM * sum(p_i * (vFull_i - vAT_i))
```

A 的绝对系数不归一化；公共部分与 T/M 差分按相对占比组合。各参考的 A 区 H 上下文仍不同，因此
`vTM_i` 不是所有参考共享的同一个张量。这里是测试过的新多参考引导定义，不是原模型原生多 A 输入。

两项都为 -1 时，使用明确的无 A 分支：A 音频及 A H 上下文清零，保留 B 的训练终止 SEP/PUL
布局及 MIDI；仍应用 Text/MIDI 差分。参考长度只用于确定共用计算窗口。

## 布局与绑定

- 左侧“A 区参考”旁的小加号是多 A 开关，亮起表示开启，说明通过悬停提示显示。
- 每条显示名称、独立控制状态、试听、跳转、解除和小 x 移除，下面是 [-1,10] CFG 滑条与当前值。窄条用状态点代替长状态文字，悬停仍显示完整状态。
- A 条数多时区域内横向滚动，支持横向手势及鼠标滚轮转横向移动，滚动条样式沿用 Take。
- 拖入 SYN 或其时间线对象：开关关闭时替换主 A；开关开启时追加参考。新增参考默认 CFG -1，避免未经用户调节就改变生成结果。
- 启用和绑定变更支持撤销/重做；数值更新沿用原采样参数的即时保存方式。
- 禁止自身、重复或循环引用，循环检查覆盖主 A 及全部启用的额外参考。逐条移除主 A 时，下一条接任并保留其 CFG；移除最后一条恢复未绑定。
- 解除主 A 时关闭双 A。启用时若缓存的第二 A 已删除、重复或形成循环，清除无效选择供重新绑定。
- 开启双 A 时不能切到暂不支持的模型，也不能切统一 CFG；先关闭双 A，其他模型仍可正常使用。

## 材料和推理

单 A 保持原 material snapshot 结构。双 A 增加可选 `multiA`：

```text
schema: aisvc.pgo-multi-a.v1
primaryUnitId
references[2..16]:
  unitId / unitRevision / guide / text / audioCfg / leadingPadFrames
```

最长参考定义公共 B 锚点；每个参考按其原生长度编码后，较短参考的 latent 与 H 在头部补零，
不拉伸或截断。A2 的参考音频单独上传，前后端及 Python 各自验证数量、身份、哈希、长度和偏移。

主 A 绑定不等于最长锚点，Take 同时保存主 A ID 及两个 `referenceSources`，审计包含实际引用的
Guide 哈希、revision、CFG、前补帧数及编码/文本张量哈希。

单次与常驻推理共用 `pgo_guidance.py`。该模块的哈希进入 runtime 和 job 身份；升级代码后已有
旧常驻 PgO 必须释放并重新加载，不能静默使用旧实现。

双 A 输出保存 FLOAT WAV，不额外归一化或硬削波。其后可使用现有 Take RMS 对齐功能。
参考编码固定 seed，B 初始噪声沿用原 Euler 采样器的 seed 行为。

## 验证与限制

- 覆盖最长参考锚点、不可变原始控制、旧单 A 快照、保存、重复/自身/循环绑定。
- 服务端覆盖两个上传、CFG、偏移及模型身份篡改拒绝。
- Python 覆盖独立公式、单 A 退化、重复相同 A 系数相加、全关闭分支无 A 上下文。
- 浏览器对比关闭前后的 A 区、摘要和时间线矩形，坐标和高度完全一致。
- 通过正式 HTTP/WebSocket 的真实 32 步 PgO 双 A 输出与对应实验输出逐值比较，最大绝对差为 0。
- 当前不支持其他模型的双 A，不把多参考解读为精准听感占比，不保证自然度或音质必然提升。
- 三参考以上的快照、上传身份、采样组合公式和删除/接任已增加针对性验证；多个可见参考的浏览器验证涵盖六条和窄视口。本次未额外跑三参考 GPU 合成。
- 同坐标下的单 A 数学退化成立；关闭双 A 后窗口恢复为主 A 原长度，不能据此保证与双 A 中
  “只保留 A1”两条不同窗口的完整采样轨迹逐位一致。
